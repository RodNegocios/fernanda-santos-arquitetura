# Materiais originais

Os 17 arquivos recebidos no repositório foram movidos integralmente para `originals/`. Nenhum original foi descartado ou sobrescrito.

O site utiliza versões WebP em `public/images/`. A fotografia principal usa uma máscara SVG em CSS para preservar o retrato original. Algumas imagens de portfólio foram enquadradas para remover bordas e controles da captura de tela; o conteúdo original permanece disponível aqui.

Esta pasta é de referência e não entra no build ou no ZIP de publicação.
